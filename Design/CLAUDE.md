# Skills Academy — instrukcje projektu

## Nazewnictwo
- Zamiast „Rdzeń" / „rdzeń" zawsze pisz **„zajęcia podstawowe"**. Termin „rdzeń" jest wycofany ze wszystkich materiałów marki.
- Zajęcia podstawowe = Useful Skills + Life Skills. Exams (egzamin ósmoklasisty, matura) stoi POZA nimi — nie jest trzecim filarem.
- Pozostałe zasady słownika marki: patrz `uploads/wytyczne-marki-kids-skills-academy.md`, sekcja 4.3.

## Język
Wszystkie materiały po polsku, z poprawnymi znakami diakrytycznymi.
